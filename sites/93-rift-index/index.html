Rift Index

Rift Index is a website for League of Legends players, listed under Lore and encyclopedia. We saw no account required. The site says it offers champion progress tracker, uses Riot API or community data, game data browser and match history and per-game detail.

Visit andrewjohnroy.com

How the site describes itself

Developer-portfolio style champion and mastery tracker: browse all 173 champions on the live patch (kit, base stats, skin gallery), look up any player's rank, champion mastery and recent matches; has an API & data sources reference. (the site says, 2026-11-25)
