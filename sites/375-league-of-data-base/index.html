League Of Data Base

League Of Data Base is a website for League of Legends players, listed under Patch notes and history and Lore and encyclopedia. The site says it offers optional account, shareable item builds, own public API and multilingual. In one test session we ran 12 checks: 8 passed and 4 partly passed. The earliest public record we found dates from July 2026.

Visit league-of-data-base.com

How the site describes itself

Free multilingual League data reference built from Data Dragon, with any-patch switching, shareable item builds, trends and an API. (the site says, 2026-11-24)
