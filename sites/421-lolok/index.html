LOLOK

LOLOK is an open-source project for League of Legends players, listed under Meta statistics. The site says it offers game data browser.

Visit gitcode.com

How the site describes itself

Static HTML/CSS/JS League data assistant on GitCode/AtomGit: quick lookup of champions, items, runes and jungle monsters (173 champions, 254 items, 27 monsters, 62 runes) with fuzzy search and multi-dimension filters; repository blurb is marked as AI-generated. (the site says, 2026-11-25)
