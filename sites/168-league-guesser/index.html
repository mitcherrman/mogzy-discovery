League Guesser

League Guesser is a web game for League of Legends players, listed under Fan game and Guessing game. We saw real-time multiplayer and playable in browser.

Visit hyesmo.itch.io

How the site describes itself

'Who am I'-style party game: each player is assigned a hidden League champion and asks yes/no questions to identify it; built to be played with friends over Discord (server-based multiplayer, about an hour per session). (the site says, 2026-11-25)
