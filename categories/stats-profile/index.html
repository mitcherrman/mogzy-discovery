League of Legends stats and profile trackers

Stats and profile sites look up a player's ranked history, recent matches, champion pool and live game. Some add overlays or desktop companions.

Check which regions are supported, how fresh the data is, whether an account or sign-in is required, how the site handles privacy, and how it is funded, since ads and subscriptions can change the experience.

Each listing on Mogzy Discovery links to the site and records what it says it does, whether it is free, which patch it shows (when it shows one), and whether we tested it, only looked at it, or are repeating its own claims.
