League of Legends damage calculators

A damage calculator works out how much damage a champion's abilities, items and runes deal against a target with given armour and magic resistance. Some also model combos, damage over time and duels.

Accuracy depends on current data and on how the tool handles scaling, penetration and rune effects. Check which patch the tool shows, which champions it supports, whether it lets you set both attacker and target, and whether it works well on a phone.

Some tools in this category are covered by our Comparison Lab, which checks fixed scenarios against expected values in a single test session. Results are per case and are not a ranking.

Each listing on Mogzy Discovery links to the site and records what it says it does, whether it is free, which patch it shows (when it shows one), and whether we tested it, only looked at it, or are repeating its own claims.
