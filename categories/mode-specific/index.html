League of Legends game-mode tools

Mode-specific tools cover game modes with their own rules, like ARAM, Arena, augment-based modes and limited-time events.

Rotating modes change often, so check how recently the tool was updated and whether it covers the mode's current rules and augments.

Each listing on Mogzy Discovery links to the site and records what it says it does, whether it is free, which patch it shows (when it shows one), and whether we tested it, only looked at it, or are repeating its own claims.
