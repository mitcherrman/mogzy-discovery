League of Legends developer resources

Developer resources include API wrappers, data libraries, asset tools and documentation for people who build League of Legends tools.

Check the licence, how recently the project was updated, which API versions or data sources it supports and whether it handles Riot's rate limits.

Each listing on Mogzy Discovery links to the site and records what it says it does, whether it is free, which patch it shows (when it shows one), and whether we tested it, only looked at it, or are repeating its own claims.

13 sites in this category.

  • Cassiopeia — Python framework for the Riot API with lazy loading, caching and data pipeline (Meraki Analytics). (Developer resource)
  • Galeforce — TypeScript Riot API wrapper (Galeforce) with the repository now under b-cho. (Developer resource)
  • Golio — Go library for the Riot Games API (Golio). (Developer resource)
  • HexDocs — Community-written developer documentation for Riot Games (League, LCU, TFT, Valorant, Runeterra): a Ghost blog of guides such as calling the Riot API from Cloudflare Workers, setting runes via the LCU API, resolving spell-text variables from CommunityDragon, and identifying champ… (Developer resource)
  • Kayn — Node.js Riot API library (Kayn). (Developer resource)
  • LeagueJS — JavaScript wrapper for the League API. (Developer resource)
  • Orianna (Developer resource)
  • Pyot — Async Python framework for the Riot API (Pyot). GitHub repository description now says DEPRECATED and points to 'pulsefire'; repository is archived. (Developer resource)
  • Riot-Watcher — Thin Python wrapper over the Riot Games API for League with a naive built-in rate limiter; docs say all public methods as of 2023-05-20 are supported and 429 errors are not retried. (Developer resource)
  • Riven — Rust library for the Riot Games API ('Riven') with generated endpoint bindings. (Developer resource)
  • Shieldbow — TypeScript/JavaScript Riot API client ('An all purpose League of Legends API Client'); repository archived. (Developer resource)
  • TeemoJS — Fast, lightweight Riot API wrapper for JavaScript ('TeemoJS'). (Developer resource)
  • Twisted — Riot Games API fetching library for JavaScript/TypeScript ('twisted'). (Developer resource)
