Comparison Lab: League tools we tested

The Comparison Lab shows what happened when we ran the same fixed scenarios through fan-made tools, starting with damage calculators. It is a record of specific checks, not a verdict on a tool.

Each result lists the scenario, the value we expected, the value the tool showed and how far apart they were. You can open a tool's page to see the full set of cases.

How we test

Every tool is tested in a single session, so a result reflects that tool at that time. A tool may have changed since, and you should check any figure that matters to you.

Scenarios come in packs pinned to one game patch. A pack records its assumptions, such as the champion, level, items, target resistances and what is left out, so the same case can be repeated later.

Each case has an expected value and a stated source: a theoretical formula, the League wiki, the in-game Practice Tool, or a project's own documentation. We say which, because those sources differ in how much weight they carry.

A tolerance is set before testing. A result within one per cent of the expected value passes; within five per cent, or correct after a documented rounding, is partial; beyond that it is a fail. Rounding a displayed value to a whole number counts as a pass.

Cases waiting on a check in the in-game Practice Tool are shown as pending. Pending is not a failure, and a case that could not be run is shown as blocked rather than failed.

There is no overall score and no ranking. Where one of Mogzy's own tools appears, it is labelled Mogzy original and shown as a reference point only. It is never presented as better than an independent tool.
